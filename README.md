# C++ Учебные проекты (2 семестр)

Данный репозиторий содержит материалы и программные решения, разработанные в рамках 2 семестра обучения по курсу программирования на C++.

## Содержимое репозитория

- **Лабораторные работы (lab6-lab17):** Реализация алгоритмов и структур данных на языке C++.
- **Самостоятельные работы (sam6-sam9):** Решение практических задач повышенной сложности.
- **Курсовой проект:** Программный комплекс "Калькулятор комплексных чисел".

## Курсовой проект: Калькулятор комплексных чисел

Проект расположен в директории `kurs/code`. Приложение разработано на языке **C++** с использованием кроссплатформенного фреймворка **Qt 6**.

### Основные возможности
- Выполнение арифметических операций над комплексными числами.
- Графический интерфейс на базе Qt Widgets.
- Интеграция с библиотекой minidocx для генерации отчетов.

### Инструкция по сборке (MSYS2/MinGW)
1. Установите окружение **MSYS2** и пакеты `mingw-w64-x86_64-qt6`, `mingw-w64-x86_64-cmake`, `mingw-w64-x86_64-ninja`.
2. Откройте терминал UCRT64.
3. Перейдите в папку проекта: `cd kurs/code`.
4. Создайте директорию сборки: `mkdir build && cd build`.
5. Сконфигурируйте проект: `cmake .. -G "Ninja" -DCMAKE_BUILD_TYPE=Release`.
6. Соберите проект: `cmake --build .`.
7. Исполняемый файл появится в папке `build`.
